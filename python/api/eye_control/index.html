    EyeControl API reference¶

    Import:

    import doly_eye

    This page documents the public API exposed by the doly_eye Python module.

    Enums¶

    EyeSide¶

    Values:

    • Both
    • Left
    • Right

    IrisShape¶

    Values:

    • Classic
    • Modern
    • Space
    • Orbit
    • Glow
    • Digi

    Classes¶

    EyeEventListener¶

    EyeEventListener() constructs the listener base. Subclass it and register it with add_listener() to receive events.

    Methods

    • onEyeStart(id: int) -> None
    • Called when an eye action/animation starts.
    • onEyeComplete(id: int) -> None
    • Called when an eye action/animation completes.
    • onEyeAbort(id: int) -> None
    • Called when an eye action/animation is aborted/stopped.

    Functions¶

    add_listener(listener: Optional[EyeEventListener], priority: bool = False) -> None¶

    Register a listener object to receive events. None does nothing. The wrapper retains the Python target until removal, clearing or accepted disposal.

    • listener: An instance of EyeEventListener or a subclass, or None.
    • priority: Insert with priority ordering (default False).

    Duplicate object registrations are permitted; each has a distinct native proxy. See callback ordering and lifetime.

    remove_listener(listener: EyeEventListener) -> None¶

    Unregister one matching object registration. listener is the Python object previously passed to add_listener(). For duplicates, the newest priority registration is removed first, otherwise the oldest normal registration. Removal does not wait for already executing callbacks to finish.

    on_start(cb: Optional[Callable[[int], None]]) -> None¶

    Set the start function callback, replacing any previous callable.

    • cb: Called as cb(id); pass None to unregister this function callback. It returns None. A noncallable, non-None value raises TypeError.

    For multiple handlers, use class-based listeners or an application dispatcher. See delayed-callback and exception behavior.

    on_complete(cb: Optional[Callable[[int], None]]) -> None¶

    Set the complete function callback, replacing any previous callable.

    • cb: Called as cb(id); pass None to unregister this function callback. It returns None. A noncallable, non-None value raises TypeError.

    For multiple handlers, use class-based listeners or an application dispatcher. See delayed-callback and exception behavior.

    on_abort(cb: Optional[Callable[[int], None]]) -> None¶

    Set the abort function callback, replacing any previous callable.

    • cb: Called as cb(id); pass None to unregister this function callback. It returns None. A noncallable, non-None value raises TypeError.

    For multiple handlers, use class-based listeners or an application dispatcher. See delayed-callback and exception behavior.

    clear_listeners() -> None¶

    Unregister all object listeners and function callbacks belonging to this component and release their stored Python targets. This does not dispose hardware or wait for callback drainage. Already executing callbacks may finish.

    init(eye_color: ColorCode, bg_color: ColorCode) -> int¶

    Initialize the eye subsystem (LCD + eye assets).

    This must be called once before other control functions.

    Parameters

    • eye_color: Default iris color (see ColorCode).
    • bg_color: Default background color (see ColorCode).

    Returns

    • int:
    Status code: - 0 : success - 1 : already initialized - -1 : loadEyeFiles failed - -2 : LCD init failed

    abort() -> None¶

    Abort/terminate the active animation.

    This preserves native cancellation behavior. It is not a native worker join or proof that subsequent image operations are safe. Prefer natural completion before image changes; avoid concurrent cancellation and image operations.

    is_active() -> bool¶

    Check whether the subsystem is active (initialized and running).

    Returns

    • bool:
    true if initialized, false otherwise.

    is_animating() -> bool¶

    Check whether an animation is currently running.

    Returns

    • bool:
    true if an animation continues, false otherwise.

    set_eyes(shape: IrisShape, iris_color: ColorCode, bg_color: ColorCode) -> int¶

    Set both iris and background to built-in presets.

    Parameters

    • shape: Built-in iris shape preset.
    • iris_color: Iris color.
    • bg_color: Background color.

    Returns

    • int:
    0: success
-1: iris preset lookup failed
-2: background preset lookup failed

    set_iris(shape: IrisShape, color: ColorCode, side: EyeSide) -> int¶

    Set iris shape and color.

    Parameters

    • shape: Built-in iris preset.
    • color: Shared doly_color.ColorCode value.
    • side: Eye side to render.

    Returns

    • int: 0 on success, -1 if the requested iris style is unavailable, or -2 if the requested shape is unavailable.

    get_iris_position(side: EyeSide) -> tuple[int, int, int]¶

    Get the current iris center position for a given side. Requires idle Eye processing.

    • side: EyeSide.Left or EyeSide.Right.

    Returns

    (status, x, y): status 0 on success, or -1 for a wrong side (including Both). Check status before using the coordinates. The top-left corner of each display is x=0, y=0; the display center is (120, 120).

    set_background(color: Color) -> int¶

    Set background color.

    Parameters

    • color: A shared doly_color.Color value.

    Returns

    • int: 0 on normal return. The ownership restrictions and exceptions below still apply.

    set_iris_image(eye_image: VContent, side: EyeSide) -> int¶

    Set iris image content for a given side.

    Parameters

    • eye_image: Iris image content.
    • side: Target eye side.

    Returns and exceptions

    Returns the nonnegative native status on success (normally 0). A None image or invalid image dimensions/channels/frames raises ValueError. A negative native assignment result becomes RuntimeError, with old/new owners retained and further guarded Eye operations blocked. Initialization and idle processing are required. See image ownership and restrictions.

    set_lid_image(lid_image: VContent, is_top: bool, side: EyeSide) -> int¶

    Set eyelid image content for a given side.

    Parameters

    • lid_image: Lid image content.
    • is_top: True for top lid, False for bottom lid.
    • side: Target eye side.

    Returns and exceptions

    Returns the nonnegative native status on success (normally 0). A None image or invalid image dimensions/channels/frames raises ValueError. A negative native assignment result becomes RuntimeError, with old/new owners retained and further guarded Eye operations blocked. Initialization and idle processing are required. See image ownership and restrictions.

    set_background_image(bg_image: VContent, side: EyeSide) -> int¶

    Set background image content for a given side.

    Parameters

    • bg_image: Background image content.
    • side: Target eye side.

    Returns and exceptions

    Returns the nonnegative native status on success (normally 0). A None image or invalid image dimensions/channels/frames raises ValueError. A negative native assignment result becomes RuntimeError, with old/new owners retained and further guarded Eye operations blocked. Initialization and idle processing are required. See image ownership and restrictions.

    set_animation(id: int, name: str) -> int¶

    Submit a named eye animation. Playback runs asynchronously, but submission can prepare image assets and wait for previous processing or rendering. A successful submission does not mean completion. Start/complete/abort are reported via EyeEvent/EyeEventListener.

    Parameters

    • id: User-defined id forwarded to event callbacks.
    • name: Animation name; use a string constant from doly_eye.expressions.

    Returns

    • int:
    0: animation accepted
-1: animation not found or required event-image preparation failed

    set_position(side: EyeSide, centerX: int, centerY: int, scaleX: float = 1.0, scaleY: float = 1.0, lid_top_end: int = 0, lid_bot_start: int = 240) -> int¶

    Set eye position and scale. Initialize Eye first and wait for idle processing.

    • side: EyeSide.Left, EyeSide.Right or EyeSide.Both.
    • centerX, centerY: Signed integer center coordinates; native accepted range is -250..250. The top-left is (0, 0), display center (120, 120).
    • scaleX, scaleY: Finite, positive scale factors, default 1.0.
    • lid_top_end: Unsigned 8-bit top-lid Y end, default 0.
    • lid_bot_start: Unsigned 8-bit bottom-lid Y start, default 240.

    Returns and exceptions

    Native integer status: 0 on success, -1 for out-of-range center coordinates. Nonfinite, nonpositive or unsafe scale magnitudes raise ValueError before rendering. Inactive Eye, busy guarded operations or uncertain image ownership raise RuntimeError.

    dispose() -> None¶

    Clean up Eye Python callbacks/listeners only. This does not call native disposal, Abort, image detachment, rendering stop or a native worker join. Image owners remain retained. From a wrapper callback this performs nonblocking logical cleanup; outside callbacks it waits only for admitted Python callback entries.

    get_version() -> float¶

    Get current library version.

    Original note: format 0.XYZ (3 digits after major).

    Returns

    • float:
    Version as float.

    Image ownership and restrictions¶

    Use VContent for raw image assignment. Initialize Eye before image assignment/position rendering and use idle processing for raw assignments, iris-position reads/rendering, and attached-image frame replacement/active-frame index reads. Python callers share a mutex; callback callers try-lock and raise RuntimeError when busy rather than blocking. Preset and animation operations retain native replacement/cancellation behavior, not a worker-join guarantee.

    All assigned images require nonempty frames, a valid active-frame index, converted 12-bit color metadata, and exact frame lengths. RGB channels must each be 0..15; alpha, where present, remains 0..255. Each channel occupies a separate byte:

    Slot Dimensions Channels
    Background Exactly 240×240 RGB
    Top/bottom lid Width 240, height 1–240 RGBA
    Iris At least 2×2 RGBA

    For each frame the byte count must equal width × height × channel count. Validation checks metadata, dimensions, channel layout, active-frame index, and frame lengths. It does not inspect individual RGB channel values; maintaining the required values is the caller's responsibility. None or invalid structural properties raise ValueError before native indexing. Eye retains native shared ownership for each slot/side; dropping Python references does not free attached content. Replacement retains old owners through the native call. If assignment fails with uncertain native ownership, old and new owners remain retained and subsequent guarded Eye operations raise RuntimeError. Stop image operations after such a failure.

    Final image owners remain resident because there is no supported detach-and-join API. Callback disposal never releases them. Preset changes may conservatively retain previous owners, which remain protected from mutation while processing. Do not mutate attached images during active processing or through external C++ callers. Do not operate LCD and Eye concurrently.

    Natural animation completion is preferred before image changes. A false is_animating() result, Abort, and wrapper mutexes are not a native join or complete shutdown proof. Native render-busy checks, cancellation and shutdown races remain limitations; wrapper coordination covers Python callers, not native workers or external C++ users.

    Lifecycle contract¶

    init(), abort() and set_animation() raise RuntimeError from any wrapper callback. Schedule these on the application control thread. dispose() is callback-only as described above; it is not renderer shutdown. The usual callback replacement, resident proxy and unraisable-exception limitations apply.

    See initialization and disposal for component-local cleanup, retained native proxies and interpreter limitations.
